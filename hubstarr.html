Precisa instalar o Docker?

O Hubstarr só precisa deste navegador; quem precisa do Docker com o plugin Compose são os arquivos que ele gera.

Linux — o script oficial instala o Docker Engine e o Compose:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Depois, para usar o docker sem sudo:

sudo usermod -aG docker $USER

Saia e entre de novo na sessão para o grupo valer.

Windows e macOS — ou Linux, se preferir uma instalação gerenciada com interface gráfica — instale o Docker Desktop, que já vem com o Compose.

Com o Docker no lugar, descompacte o .zip e suba a stack de dentro da pasta dos arquivos:

docker compose up -d
