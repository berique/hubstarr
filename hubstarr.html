Prototype. Hubstarr was not designed for production use: the files it generates are a starting point, with no security hardening, backups or monitoring. Review everything — passwords, ports, certificates and permissions — before exposing the stack to any network other than your own.

No Docker Compose on this server. Hubstarr still generates the files and keeps the stack, but Bring up and Tear down will fail until the Compose plugin is installed — see below how to install it.

The saved stack could not be read. The server answered with an error, so the page is showing an empty stack that is not yours — and, so as not to write over what is in the database, it saves nothing while this lasts. Check the browser console for the error and reload once it is fixed.

Need to install Docker?

Hubstarr itself only needs this browser; it is the files it generates that need Docker with the Compose plugin.

Linux — the official script installs Docker Engine and Compose:

curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

Then, to use docker without sudo:

sudo usermod -aG docker $USER

Log out and back in for the group to take effect.

Windows and macOS — or Linux, if you prefer a managed install with a GUI — get Docker Desktop, which ships with Compose.

With Docker in place, unzip the .zip and bring the stack up from inside the files folder:

docker compose up -d
